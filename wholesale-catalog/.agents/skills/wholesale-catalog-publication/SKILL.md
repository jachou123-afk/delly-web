# 批發目錄上架與下架

## 角色商品的正版查核

- 核對商品品名、報價文案、主圖、附圖和包裝。可辨識的第三方角色系列均適用，包含三麗鷗（如 Hello Kitty、酷洛米）、蠟筆小新及其他角色系列，也涵蓋混款商品及各分類的既有上架品。
- 以來源試算表的實際分頁 ID 和 NO 對到同款、同來源的供應商報價原文，優先讀 `_報價依據` 的 `raw_source`，必要時核對 `_微信確認紀錄` 的完整原文。原文明確肯定該商品是「正版」（包含「正版授權」）才可公開。合報價或混裝時，逐款確認正版聲明涵蓋每一個對外提供的角色款。
- 缺少同款的明確正版聲明時，標記「報價原文未註明正版」，保留於內部。單有「授權」、雷標、包裝上的正版字樣、網站分類或同批其他商品的正版聲明，都不足以放行。「正版同款」、「正版風格」、否定或待確認語句也不足以放行。符合明文條件才設 `licensedLabel: true`，另按報價來源獨立核對 `laserLabel`。

## 同步與既有商品

- 草稿若沿用上一次結果，依原分頁 ID 和 NO 將不符合的列送入 `onHold: true`，或在發布前從沿用的草稿移除同一筆，防止下次同步把它帶回公開目錄。正式 no2 作為唯讀來源，內部報價、採購與 LINE 廣告流程依各自的授權範圍處理。
- 店主指定歷史原表的上架批次時，原表同樣唯讀。以該原表的試算表 ID、實際分頁 ID 和 NO 追溯同款，查核 15% 報價、規格和來源圖片綁定，並檢查正式站已有商品是否重複。
- 下架已公開的商品時，移出發布資料，清理該批商品專用的公開圖檔。先確認保留商品的圖片引用。發布後以未登入狀態核對列表、搜尋、既有商品連結及曾公開的圖片網址。
