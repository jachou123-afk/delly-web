# 筆電 Agent 廣告選品交接

店主從私人批發目錄勾選並送出商品後，從「查看待審批次」按「下載圖文包（ZIP）」。筆電 Agent 可整批讀取已保存的選品、當時選定的毛利率與售價、箱入數、已驗收圖片及 LINE 文案。 [私人批發目錄](https://toy-wholesale-catalog-review.vicchou.chatgpt.site/)

## 給筆電 Agent 的提示詞

> 請到私人批發目錄的「查看待審批次」，以擁有者帳號下載最新批次的圖文包。解壓到這次專用的資料夾，讀取「發送順序與說明.txt」或 manifest.json，依 BGD 商品編號查重並逐款回報建議發送、已發過或暫緩及理由。等我確認批次、聊天室與範圍後，再依現行 LINE 發送程序接續。確認每款圖片和文案都出現在正確聊天室後記錄結果。中斷時依已確認的紀錄接續。這次先交付判斷結果。

## 下載包內容

- 每款以序號和 BGD 品號建立資料夾，內含 `文案.txt`、`圖片01` 及該批次保存的附圖。圖片按目錄的已驗收檔案格式保留，發送前確認 LINE 預覽正常。
- 匯出時，已核對由同張首圖裁出且內容完整重複的附圖會自動略過。其餘附圖包含獨立拍攝、高解析度細節及來源未確認的照片。可在批次的發送順序說明核對省略張數，完整圖組可在商品頁查看。
- ZIP 以批次保存資料為準。早期只保存主圖的批次會匯出該張主圖。單包上限為 32 MiB，素材較大時可分成幾個較小批次。

## 讀取方式

- 有 Sites 連接器時，先用 `sites_read_database_overview` 從已登入的擁有者專案確認 D1 綁定 `DB` 與資料表 `ad_selection_batches`，再用 `sites_read_database_table_rows` 唯讀取得批次。依 `status` 找 `pending`，依 `created_at` 查詢時間順序，從 `products_json` 讀取各款內容。若工具回應標記數值截斷，改從擁有者目錄讀取完整批次。
- 有擁有者瀏覽器時，可直接開啟目錄的「查看待審批次」並下載 ZIP。同一登入工作階段也可讀取 `/api/ad-selections?status=pending`。商品連結、圖片和待審文案均供內部判斷。
- 查看原有批次的進度與重複紀錄時，沿用正式工具的「發送管理」。如紀錄不完整，將該款列為待查，並寫出缺少的證據。 [正式 LINE 執行規範](https://github.com/jachou123-afk/delly-web/blob/main/quote_dispatch/LINE_COMPUTER_USE_SOP.md)
